# 🚗 Mile to Kilometre Converter

A simple GUI application built with Python Tkinter that converts miles to kilometres.

---

## 🎯 Project Overview

This project is a beginner-friendly Tkinter application that takes a value in miles and converts it to kilometres using the conversion factor: **1 mile = 1.60934 km**.

---

## 🚀 Features

| Feature | Description |
|---------|-------------|
| **User Input** | Enter miles in the input field |
| **Calculate** | Click the "Calculate" button to convert |
| **Instant Result** | Displays the converted value in kilometres |
| **Clean GUI** | Simple and intuitive interface |
